# قمر الروايات — واجهة الموقع

هذا الموقع متصل بالخادم المشترك نفسه الذي تستخدمه وظائف الترجمة والإدارة. مستودع الواجهة `ZeUsx313/New-moon-2` يحتوي React/Vite/TypeScript، ومستودع [الخادم C](https://github.com/cobrapk8ggggggg-tech/C) يحتوي API وتنفيذ الترجمة والتخزين. اختلاف المستودعين لا يعني وجود نظامي ترجمة منفصلين.

أضيفت واجهة ChatGPT Android وGemini Web وDeepSeek 3MH / Telegram في **لوحة التحكم ← إعدادات المترجم**. تشمل مشاريع ChatGPT وإنشاء المحادثات والمرفقات، ومحادثة مستقلة لكل من الترجمة والمصطلحات والمراجعة والعناوين والبيانات، مع الحفاظ على جميع الإعدادات عند التحميل والحفظ.

- [دليل الإعداد والتوافق مع الخادم](docs/account-providers.md)
- [المراجعة التفصيلية لبنية الموقع](docs/source-review.md)
- [جرد جميع الملفات الأصلية واعتمادياتها ومساراتها](docs/source-inventory.json)
- [الاختبارات وإعادة تشغيلها](docs/testing.md)

```sh
npm ci
npm run dev
```

عنوان الخادم يأتي من `VITE_API_URL`، ويستخدم الموقع العنوان الأصلي عند غياب المتغير. لا توضع توكنات حسابات الذكاء الاصطناعي أو الكوكيز في ملفات البيئة العامة للموقع؛ تُدخل من لوحة الإعدادات وتُرسل إلى الخادم المحمي بالمصادقة.

```sh
npm run lint
npm test
npm run build
```

اختبار المتصفح المتكامل يحتاج نسخة الخادم المعدل واعتماديات اختباره؛ التفاصيل في دليل الاختبارات. لا تتضمن ملفات الاختبار بيانات حسابات حقيقية.
