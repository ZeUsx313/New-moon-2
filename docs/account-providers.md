# حسابات المزوّدين في الموقع

الموقع يتصل بالخادم المشترك عبر `src/services/accountProviders.ts`. عنوان API الافتراضي هو `https://c-production-6948.up.railway.app`، ويمكن تخصيصه عبر `VITE_API_URL`. الواجهة والخادم مستودعان منفصلان ويجب نشر إصدارين متوافقين؛ CI يثبت إصدار الخادم المستخدم لاختبارات الموقع.

## الاستخدام

1. افتح إعدادات المترجم وأضف ChatGPT Android أو Gemini Web أو DeepSeek 3MH.
2. الصق access token لحساب ChatGPT/DeepSeek، أو كوكيز Google بصيغة `name=value; name=value`. لوحة الربط تستخدم أول حساب في القائمة.
3. اضغط **ربط الحساب وجلب الخيارات**. لا تحتاج معرّف حساب أو مشروع أو محادثة، ولا رقم حساب Google أو ترويسة نموذج.
4. افتح مهمة الترجمة أو المصطلحات أو المراجعة أو العناوين أو البيانات. اختر نموذجًا ومحادثة لكل مهمة، أو اتركها لإنشاء محادثة مستقلة تلقائيًا لكل تشغيل.
5. في ChatGPT، اختيار المشروع يجلب محادثاته من مسار المشروع، مع طلب المزيد عند توفر cursor؛ معاينة sidebar ليست القائمة الكاملة.
6. زر **إنشاء محادثة** يرسل تعليمات تهيئة قصيرة تلقائيًا ويختار المحادثة الجديدة. لا يتطلب رسالة مكتوبة.
7. احفظ الإعدادات لتثبيت الاختيارات. قسم تجربة الرسائل والمرفقات اختياري.

## بيانات يجلبها الخادم

- ChatGPT: يستخرج account ID من JWT أو يكتشفه من حساب الجلسة عند استخدام توكن opaque. يزيل بادئة Bearer عند لصقها. يجلب النماذج والمشاريع والمحادثات والـcurrent node تلقائيًا. طلب sidebar يستخدم `conversations_per_gizmo=5` كما في الملف المرفق لتفادي طلب 50 غير المتوافق؛ توجد اختبارات تمنع رجوع القيمة الخاطئة.
- Gemini: يكتشف الحساب المتاح عبر جلسة Google وGetUserStatus، ويجلب أحدث المحادثات والنماذج المتاحة. يجلب response/choice IDs عند اختيار محادثة ويولّد ترويسة النموذج في الخادم. لا يرسل CSRF أو ترويسات النموذج إلى الواجهة. قائمة المحادثات نافذة حديثة يمكن توسيعها حتى 200، وليست ادعاءً بإرجاع سجل الحساب الكامل. بروتوكول الحساب لا يقدم مشاريع مماثلة لمشاريع ChatGPT؛ لا تعرض الواجهة قائمة مشاريع وهمية.
- DeepSeek 3MH: يجلب النماذج والجلسات من خدمة المستخدم المحددة، ويختار معرّف الجلسة ومعلومة parent إن أعادتها الخدمة. الرابط الافتراضي والإعدادات العددية لا تتطلب تعبئة. خيارا التفكير والبحث متاحان. يصل توكن DeepSeek إلى خدمة 3MH لتنفيذ الطلب.
- مستويات تفكير ChatGPT تعرض كقائمة فقط إذا أعلنها رد النماذج؛ غير ذلك يُستخدم إعداد الحساب الافتراضي. لا توجد كتابة يدوية لمستوى غير معروف.

## وضع الفقرات في Gemini

مفتاح **تقسيم الفصل وفحص الفقرات** يظهر في إعدادات Gemini وحده، ويمكن تغييره دون ربط الحساب أولًا. مفعّل افتراضيًا؛ أوقفه ثم احفظ الإعدادات لإرسال الفصل كاملًا دون تقسيم أو علامات الفقرات. أعد تشغيله واحفظ للعودة إلى الترجمة المقسّمة وفحص التغطية. الإعداد مستقل لكل مزوّد Gemini ويحفظ في `geminiParagraphMode`؛ القيمة false تبقى محفوظة بعد إعادة تحميل الصفحة.

ChatGPT وDeepSeek يرسلان الفصل كاملًا بالطريقة العادية دائمًا؛ لا يطبّق عليهما هذا النظام حتى لو وُجدت إعدادات تقسيم قديمة. يبقى فحص جودة الفصل العام قائمًا. حجم الجزء لا يؤثر إلا على Gemini عندما يكون وضع الفقرات مفعّلًا.

لا تنفذ الواجهة ترجمة الفصول مباشرة. الترجمة وفحوص تغطية الفقرات الاختيارية في Gemini وحالة المحادثات المستأنفة تعمل في الخادم وMongoDB. إعدادات الإصدارات السابقة تبقى قابلة للحفظ للاستفادة من القيم الموجودة دون طلب إعادة إدخالها.

## الأخطاء والحفظ

عمليات الحسابات محمية بتسجيل الدخول وصلاحية الإدارة في الخادم. لا تحفظ بيانات المزودين في تخزين المتصفح. الردود نصوص React دون HTML خام. تغيير بيانات الحساب يمسح القوائم والمرفقات المؤقتة، والرد المتأخر لا يطبّق على رمز مختلف. الطلبات التي تنشئ رسائل أو ترفع مرفقات لا تعاد تلقائيًا. فشل الطلب يحافظ على الاختيارات والمرفقات. مسار غير موجود يعرض حاجة الخادم إلى التحديث؛ 401/403 من المزوّد تعرض مشكلة بيانات الحساب؛ 422 تعرض رفض صيغة الطلب دون تسريب تفاصيل التوكن.

المرفقات تخص رسالة التجربة التالية، بحد 10 MB وعشرة مرفقات؛ لا تضاف تلقائيًا إلى مهام ترجمة الفصول. يمكن إضافة مزوّد OpenAI مخصص بالطريقة القديمة؛ عنوان API الخاص بمزوّد مخصص لا يمكن استنتاجه من مفتاحه.
